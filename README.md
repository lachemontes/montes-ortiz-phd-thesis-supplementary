# Supplementary material: Montes-Ortiz PhD thesis (Lund University, 2026)

**Thesis:** Evolution of multigene families in insect and non-insect arthropods: From chemosensory receptors to genome-wide specialization

**Author:** Zaide Montes-Ortiz, Department of Biology, Lund University, Sweden

**Public defense:** 4 December 2026

This repository contains supplementary figures, tables, sequences, and analysis outputs that could not be included in the printed thesis because of its format.

## Contents

| Folder | Content |
|---|---|
| `Paper_I/` | *Argiope bruennichi*: curated receptor sequences, phylogenetic trees, chromosome maps, expression tables (TPM and DESeq2), and supplementary figures |
| `Paper_II/` | *Ixodes ricinus*: curated receptor sequences, phylogenetic trees, expression data, and supplementary figures |
| `Kappa/` | Analyses performed for the thesis summary: GR C-terminal motif analysis (MEME, CD-HIT, shuffled control, TOMTOM, and FIMO outputs), and source data and scripts for the summary figures |
